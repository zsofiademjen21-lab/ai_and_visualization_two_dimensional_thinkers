AstroVision Model Explorer

An interactive tool to explore where the galaxy classifier gets things right and wrong. For the short version, see the key takeaways.

1Pick a group of galaxies. Click a square in the table of answers (for example "true Irregular, model says Spiral"), or use the "All mistakes" button.
2See where they are. The selected galaxies light up on the map and appear as pictures in the gallery at the bottom.
3Click a picture to see how sure the model was about each class.

The model has 5 classes: Spiral, Elliptical, Edge-on Disk, Irregular (called "Disturbed" in the original 10 Galaxy10 types) and Merger.

What the model answers for each true class

Each row is one true class; each column is the model's answer. Outlined squares are correct answers. Look for: dark squares outside the outlined ones, which are common mistakes.

How often each class is recognised

Share of each true class that the model gets right. Look for: short bars, which are classes the model struggles with.

Map of the model's answers

Each dot is a galaxy. Galaxies close together got similar answers from the model (t-SNE of its output probabilities). Hover a dot to see the galaxy, click to inspect it. Look for: orange mistakes gathering in the same places.

Is the model as sure as it should be?

When the model says it is X% sure, is it right X% of the time? If yes, the dots lie on the grey diagonal line. Look for: dots below the line, where the model is overconfident.

Does the answer depend on what the galaxy looks like?

Pick a property (for example apparent size) and a true class. Each bar is a group of galaxies, from low to high values of that property (same number of galaxies per bar). Grey = answered correctly, colours = what the model said instead; the number on top is % correct. Click a coloured part to see those galaxies. Look for: bars where the coloured part grows, which shows what makes the model go wrong.
